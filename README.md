# CPU Scheduling Simulation Project

## Members
- Antikot Gemtessa
- Sean Redd

## Description
This project is a CPU Scheduling Simulation written in Java for COSC 439 Operating Systems.

The project implements:
- First-Come First-Served (FCFS)
- Round Robin Scheduling
- Priority Scheduling

The program calculates:
- Waiting Time
- Turnaround Time
- Ready Queue Time
